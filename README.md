# Лабораторная работа 2. Вычисления и проверка результата

## Запуск программ
Каждая программа запускается через терминал командой:
- python time_parts.py
- python purchase.py
- python variant.py

---

## Задание 3. Предсказание результатов операций

| Выражение | Мой прогноз | Результат Python | Объяснение |
|---|---|---|---|
| 2 + 3 * 4 | 14 | 14 | Умножение выполняется раньше сложения |
| (2 + 3) * 4 | 20 | 20 | Скобки изменяют приоритет операций |
| 17 // 5 | 3 | 3 | Целочисленное деление с округлением вниз |
| 17 % 5 | 2 | 2 | Остаток от деления 17 на 5 |
| -7 // 2 | -4 | -4 | Округление вниз до меньшего целого (-3.5 округляется до -4) |

## Проверки и результаты

### 1. Перевод времени (time_parts.py)
- Вход: 0 -> Результат: 0 ч 0 мин 0 с
- Вход: 59 -> Результат: 0 ч 0 мин 59 с
- Вход: 60 -> Результат: 0 ч 1 мин 0 с
- Вход: 3600 -> Результат: 1 ч 0 мин 0 с

### 2. Стоимость покупки (purchase.py)
- Вход: цена 45, количество 3, оплата 135 -> Стоимость: 135, Сдача: 0
- Вход: цена 45, количество 0, оплата 100 -> Стоимость: 0, Сдача: 100

### 3. Индивидуальный вариант (variant.py)
- Вход: объем 0, вместимость 10 -> Полных: 0, Остаток: 0, Всего: 0
- Вход: объем 20, вместимость 10 -> Полных: 2, Остаток: 0, Всего: 2
- Вход: объем 21, вместимость 10 -> Полных: 2, Остаток: 1, Всего: 3
- Дополнительно (радиус 1): Длина окружности = 6.28, Площадь круга = 3.14
